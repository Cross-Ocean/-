# Anti-UAV｜无人机检测与追踪系统

基于 YOLO、OpenCV 和 ZeroMQ 的无人机视觉检测与追踪项目，包含可视化界面、树莓派摄像头传输与舵机控制代码，以及海康摄像头云台跟踪脚本。

本仓库提供项目源码、模型权重和数据集下载入口，便于学习、复现与二次开发。

## 主要功能

- **目标检测**：使用 YOLO 模型检测无人机，显示检测框与目标中心坐标。
- **桌面界面**：展示原始画面、检测结果、检测框数量及连接状态。
- **目标位置可视化**：显示目标在图像中的相对位置和位置轨迹。
- **图像传输**：树莓派采集摄像头画面，通过 ZeroMQ 发送至电脑端。
- **坐标回传**：电脑端将选定目标的中心坐标发送至树莓派。
- **舵机控制**：树莓派根据目标坐标控制舵机，实现扫描与追踪。
- **日志记录**：提供检测记录查看与 CSV 导出功能。
- **海康摄像头接入**：提供基于海康 SDK 的检测与云台跟踪脚本。

> 界面中的目标位置图基于摄像头图像坐标绘制，不代表实际雷达测距结果。

## 系统工作流程

```text
树莓派摄像头
    │
    │ 图像传输：ZeroMQ / TCP 5556
    ▼
电脑端 YOLO 检测与界面显示
    │
    │ 目标中心坐标：ZeroMQ / TCP 5555
    ▼
树莓派舵机控制程序
    │
    ▼
云台扫描与目标追踪
```

树莓派方案与海康摄像头方案为不同的硬件接入方式，请根据设备选择对应代码。

## 环境准备

### 电脑端

主要 Python 依赖：

```bash
python -m pip install ultralytics opencv-python numpy pyzmq PySide6
```

### 树莓派端

图像传输程序使用 OpenCV 和 PyZMQ；舵机控制程序还依赖：

- NumPy
- `RPi.GPIO`
- 与当前硬件适配的 `PCA9685` 驱动模块

`main2.py` 使用以下导入方式，请提前准备对应驱动，并确认 Python 能够找到该模块：

```python
from PCA9685 import PCA9685
```

硬件包括树莓派、可用摄像头，以及运行舵机控制所需的 PCA9685 控制板和舵机。接线、供电及角度范围应与实际设备一致。

## 快速开始：树莓派方案

### 1. 获取代码

```bash
git clone https://github.com/Cross-Ocean/Anti-UAV.git
cd Anti-UAV
```

### 2. 配置网络

电脑与树莓派需要能够互相访问，并允许对应端口通信。

| 数据方向 | 端口 | 配置位置 |
|---|---|---|
| 树莓派 → 电脑：图像帧 | TCP 5556 | 电脑端界面的树莓派 IP 输入框 |
| 电脑 → 树莓派：目标坐标 | TCP 5555 | `main2.py` 中的 `subscriber.connect(...)` |

运行前，将 `main2.py` 中的坐标订阅地址改为实际电脑 IP：

```python
subscriber.connect("tcp://你的电脑IP:5555")
```

### 3. 启动树莓派图像传输

在树莓派的项目根目录执行：

```bash
python3 "code/树莓派/pi_camera_frame_publisher.py" --camera 0 --width 320 --height 240
```

如果摄像头编号不是 `0`，请修改 `--camera` 参数。

### 4. 启动电脑端界面

在电脑的项目根目录执行：

```bash
cd app
python app.py
```

当前代码中的权重路径为 `../best.pt`，因此请从 `app` 目录启动。

界面默认登录信息：

```text
用户名：admin
密码：admin
```

输入实际树莓派 IP 后登录，并点击“开始标记”查看检测标注。

> 当前登录逻辑为源码内置的演示实现。界面上的“开始标记 / 停止标记”主要控制结果显示，不能作为舵机控制的急停开关。

### 5. 启动舵机控制

确认驱动、接线、电脑 IP 和舵机参数正确后，在树莓派的项目根目录执行：

```bash
python3 "code/树莓派/main2.py"
```

当前控制程序以图像中心 `(160, 120)` 计算偏差，对应 `320 × 240` 图像。若修改摄像头分辨率，需要同步调整控制程序及界面中的中心坐标相关设置。

## 主要检测参数

电脑端界面的默认参数位于 `app/app.py`：

| 参数 | 默认值 | 含义 |
|---|---|---|
| `MODEL_PATH` | `../best.pt` | 模型权重路径 |
| `IMG_SIZE` | `640` | YOLO 推理输入尺寸 |
| `DEVICE` | `cpu` | 推理设备 |
| `CONF` | `0.25` | 检测结果筛选阈值 |
| `CLASS_ID` | `0` | 目标类别编号 |
| `COORD_TOPIC` | `green_target` | 坐标消息主题 |

目标类别编号需与模型训练时的类别定义一致。界面可以显示多个检测框；当前坐标回传逻辑选择其中面积最大的检测框作为控制目标。

## 海康摄像头方案

对应脚本：

```text
code/海康/hik_auto_tracking_modular.py
```

该脚本使用 Windows 接口及海康 SDK，运行前需要：

1. 准备兼容的海康摄像头及云台设备。
2. 配置海康 SDK，包括 `HCNetSDK.dll` 及其依赖库。
3. 检查脚本中的 SDK 路径、设备连接信息和模型权重路径。
4. 确认 Python 与 SDK 的位数兼容。

该方案需要额外的硬件和 SDK 配置，仅安装 Python 依赖不足以运行。
